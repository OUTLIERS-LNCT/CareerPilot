# CareerPilot AI — AI-Powered Placement Preparation Platform

An AI-powered placement preparation platform designed to help students prepare for technical interviews and campus placements through personalized learning roadmaps, skill assessments, resume analysis, and AI-driven mock interviews.

CareerPilot AI analyzes a student's target role, preparation timeline, and assessment performance to help identify skill gaps and organize preparation into actionable tasks. The platform integrates a React frontend, FastAPI backend, PostgreSQL database, and LLM-powered features to deliver a structured and personalized placement preparation experience.
